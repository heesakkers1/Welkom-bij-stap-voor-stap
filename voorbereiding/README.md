# Voorbereiding nieuwe collega

Interactieve checklist voor de begeleiders: wat er vóór de eerste werkdag van
een nieuwe collega geregeld moet zijn. Staat bewust los van de onboardingsite,
want de nieuwe collega hoeft dit niet te zien.

Op Vercel is dit een eigen project uit dezelfde GitHub-repository, met als
Root Directory `voorbereiding`.

- `npm install` en daarna `npm run dev` om lokaal te bekijken.
- De inhoud van de checklist staat in `src/data.js`.
